## How to capture

In Power BI Desktop, open each page and use **Windows + Shift + S** to snip, or
press **Print Screen** and crop. Capture the report canvas only — no Windows
taskbar, no Power BI ribbon or left-hand navigation pane, so the images look like
a dashboard rather than a screenshot of an application.

`data-model.png` comes from the **Model view** (the third icon down the left edge
of Power BI Desktop).

## Before sending

Check each image for anything identifying that shouldn't be public — file paths in
title bars, account names in the top-right corner, or a visible Windows username.
